# MyVersionOfSpeechify Studio (v2.0 Neural AI)

A modern, high-fidelity AI text-to-speech studio and developer code-reading assistant powered by **Amazon Polly Neural AI**, **Node.js/Express**, and **React**.

Transform written articles, documentation, books, and programming code snippets into natural, human-like speech with crystal-clear intonation and intelligent code comprehension.

## What's New in Version 2.0

- 🧠 **Amazon Polly Neural AI Engine**: State-of-the-art deep learning synthesis producing realistic human intonation, conversational flow, and natural breathing. Toggle between **Neural AI** (default) and **Standard Concatenative** engines.
- 💻 **Smart Code Reader & Comprehension**: Intelligently translates programming syntax, identifiers (`camelCase`, `snake_case`), operators (`===`, `=>`, `&&`, `||`, `++`), block delimiters, and comments into natural spoken developer dialogue or detailed syntax readout.
- 🧩 **Chrome Browser Extension (Manifest V3)**: Highlight text or code anywhere on the web, right-click, and select **"Read with Speechify (Neural AI)"** or **"Send to Speechify Web App"**. Includes a floating in-page audio widget and toolbar popup player.
- 🍎 **macOS Quick Action & Terminal CLI**: Convert clipboard content directly into spoken audio using your Mac speakers via `afplay` (`pbpaste | ./speechify-clip.sh`).
- 🌊 **Studio Audio Player & Visualizer**: Interactive canvas soundwave visualizer, scrubber timeline, ±5s jump controls, speed presets (0.75x to 2.0x), MP3 download, and session history drawer.
- 🔑 **Flexible AWS Authentication**: Native support for environment variables, `.env` files, AWS CLI SSO profiles (`aws sso login`), and default AWS credential provider chains.
- 📁 **Document & Code File Upload**: Drag-and-drop `.txt`, `.md`, `.js`, `.ts`, `.py`, and `.json` files for instant synthesis.

## Smart Code Reader (How It Understands Code)

Raw text-to-speech engines struggle with programming syntax, skipping operators or mispronouncing identifiers. The built-in **CodeSpeechEngine** automatically parses code syntax into natural, spoken English:

| Raw Code Syntax | Spoken Neural Translation |
| :--- | :--- |
| `const total = items.reduce(...)` | *"Declare constant total equals items dot reduce with argument..."* |
| `if (x === 0 && !isValid)` | *"If x strictly equals 0 and not is Valid, then opens block..."* |
| `user_account_id` / `fetchUserProfile` | Splits snake_case & camelCase into *"user account id"* and *"fetch User Profile"* |
| `(acc, curr) => acc + curr` | *"acc, curr arrow function acc plus curr"* |
| `// TODO: Refactor loop` | *"Comment: to do: Refactor loop."* |

Two modes are available in the UI:
1. **Natural Flow**: Reads code like a senior developer explaining it in a code review.
2. **Detailed Syntax**: Vocalizes exact braces, brackets, semicolons, and structure for audio-only auditing.

## Getting Started

### Prerequisites

- **Node.js**: v18.0.0 or higher (tested on Node v22).
- **AWS Account**: An AWS account with permissions for `polly:SynthesizeSpeech` and `polly:DescribeVoices`.

---

### 1. AWS Credentials Configuration

You can configure AWS credentials using any of the following methods:

#### Option A: `.env` File (Recommended for Local Dev)
Copy `.env.example` to `.env` in the repository root:
```bash
cp .env.example .env
```
Fill in your credentials:
```env
AWS_REGION=us-west-2
AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY

# Required if using temporary credentials or AWS SSO
AWS_SESSION_TOKEN=your_session_token_here

PORT=5001
```

#### Option B: Terminal Environment Variables
```bash
export AWS_REGION="us-west-2"
export AWS_ACCESS_KEY_ID="your_access_key_id"
export AWS_SECRET_ACCESS_KEY="your_secret_access_key"
export AWS_SESSION_TOKEN="your_session_token"  # If using SSO/STS
```

#### Option C: AWS CLI SSO Login
If you use AWS SSO:
```bash
aws sso login
```
The server automatically loads credentials using `AWS_SDK_LOAD_CONFIG=1` and the standard AWS credential chain.

---

### 2. Starting the Backend Server

```bash
# In the repository root
npm install
node server.js
```
The server runs on **`http://localhost:5001`**.

---

### 3. Starting the React Web Studio

```bash
# In a new terminal tab
cd myversionofspeechifyUI
npm install
npm start
```
The web application will open on **`http://localhost:3000`**.

## Chrome Browser Extension

Use MyVersionOfSpeechify directly from any website in Google Chrome or Chromium browsers.

### Installation
1. Open Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** (toggle in top right corner).
3. Click **Load unpacked**.
4. Select the `chrome-extension/` directory inside this repository.

### Features
- **Right-Click Context Menu**: Select any text on a webpage, right-click, and choose:
  - 🔊 **"Read selection with Speechify (Neural AI)"**: Converts and plays audio directly on the page via a sleek floating widget.
  - 💻 **"Read selection as Code"**: Runs the selection through the Code Reader preprocessor.
  - 🚀 **"Send to Speechify Web App"**: Opens `http://localhost:3000` with the text pre-loaded.
- **Extension Toolbar Popup**: Quick converter, voice selector, speed pills, and mini audio player.

## macOS Quick Action & Clipboard Script

To synthesize and listen to your macOS clipboard instantly through your Mac speakers:

```bash
# Listen to current clipboard text
pbpaste | ./speechify-clip.sh

# Listen to a direct string
./speechify-clip.sh "Hello world, this is Neural AI speech."

# Listen to code with Smart Code Reader
cat server.js | ./speechify-clip.sh --code
```

### Setting up a Global macOS Keyboard Shortcut (Quick Action):
1. Open the **Automator** app on macOS -> File -> New -> **Quick Action**.
2. Set "Workflow receives" to **no input** (or **text**).
3. Add a **Run Shell Script** action:
   ```bash
   pbpaste | /path/to/myversionofspechify/speechify-clip.sh
   ```
4. Save as `Read with Speechify`.
5. In **System Settings** -> **Keyboard** -> **Keyboard Shortcuts** -> **Services**, assign a shortcut (e.g. `Cmd + Shift + S`).

## API Reference

### `POST /synthesize`
Synthesizes speech from text or code.
- **Request Body**:
  ```json
  {
    "text": "Text to synthesize",
    "voiceId": "Joanna",
    "engine": "neural",
    "codeMode": "natural",
    "rate": "100%",
    "pitch": "default"
  }
  ```
- **Response**:
  ```json
  {
    "success": true,
    "audioUrl": "http://localhost:5001/audio-uuid.mp3",
    "filename": "audio-uuid.mp3",
    "engine": "neural",
    "voiceId": "Joanna",
    "codeModeApplied": true
  }
  ```

### `GET /voices`
Returns available Amazon Polly voices with supported engines (`neural`, `standard`), language codes, and gender.

### `GET /status`
Returns server operational health, region, active AWS credentials status, and feature list.

### `POST /upload`
Uploads a document or code file (`.txt`, `.md`, `.js`, `.py`, `.json`, etc.) for extraction and synthesis.

### `POST /api/clip` & `GET /api/clip/latest`
Sync queue used by the browser extension and macOS scripts to send clipped text to the open React studio.
